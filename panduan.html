Safety Guide

Panduan keselamatan kebakaran

🧯 Teknik PASS — Cara Guna Alat Pemadam Api

1
Pull — Tarik

Tarik pin keselamatan pada pemegang.

2
Aim — Halakan

Halakan muncung ke pangkal api, bukan asap.

3
Squeeze — Tekan

Tekan pemegang secara perlahan dan tetap.

4
Sweep — Sapukan

Sapukan dari sisi ke sisi sehingga api padam.

🚪 Semasa Kebakaran

Tetap tenang — jangan panik atau berlari.
Aktifkan penggera kebakaran terdekat.
Guna alat pemadam hanya jika api masih kecil & terkawal.
Jika api membesar, keluar segera ikut laluan kecemasan.
Berkumpul di titik kumpul (assembly point) yang ditetapkan.
⚠ AMARAN
JANGAN GUNA LIF SEMASA KEBAKARAN!

Bekalan elektrik boleh terputus. Guna tangga kecemasan / laluan keluar.
