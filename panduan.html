Panduan keselamatan kebakaran

🧯 Teknik PASS — Cara Guna Alat Pemadam Api

1
Pull (Tarik)

Tarik pin keselamatan pada pemegang.

2
Aim (Halakan)

Halakan muncung ke pangkal api, bukan ke asap.

3
Squeeze (Tekan)

Tekan pemegang secara perlahan dan tetap.

4
Sweep (Sapukan)

Sapukan dari sisi ke sisi sehingga api padam.

🚪 Semasa Kebakaran

  • Tetap tenang — jangan panik atau berlari.
  • Aktifkan penggera kebakaran terdekat.
  • Guna alat pemadam api hanya jika api masih kecil dan terkawal.
  • Jika api membesar, tinggalkan segera melalui laluan kecemasan terdekat.
  • Jangan sekali-kali guna lif semasa kebakaran.
  • Berkumpul di titik kumpul (assembly point) yang ditetapkan.
